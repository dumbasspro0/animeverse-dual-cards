# AnimeVerse Card Duels

An anime-inspired collectible card game interface built with React and Vite.

## Features

- Browse and search character cards
- Filter and sort cards
- View character details and power levels
- Explore a card-duel interface
- Responsive, anime-inspired UI design

## Tech Stack

- React
- JavaScript
- Vite
- CSS

## Getting Started

### Prerequisites
Install [Node.js](https://nodejs.org/).

### Installation

Clone this repository, open the project folder in your terminal, and run:

```bash
npm install
npm run dev
```

Open the local URL displayed in your terminal, usually `http://localhost:5173`.

## Artwork

The cards use custom CSS-based poster artwork and symbols rather than official character images.
