# AnimeVerse: Card Duels

A responsive anime-inspired collectible card game UI built with React, Vite and CSS.

## Features
- Ten starter champions from ten anime worlds
- Search and filter the collection
- Sort by power or name
- Open character details
- Choose your champion and duel a computer opponent
- Responsive design

## Run locally
Install Node.js, then in this folder run:

```bash
npm install
npm run dev
```

Open the local URL shown in your terminal, usually http://localhost:5173.

## Upload to GitHub
Create an empty GitHub repository, then run these commands in the project folder (replace YOUR-USERNAME):

```bash
git init
git add .
git commit -m "Build AnimeVerse Card Duels"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/animeverse-card-duels.git
git push -u origin main
```

## Artwork
Cards use custom CSS poster-style artwork and symbols rather than bundled copyrighted character images. Replace the art panels with images you have permission to use if desired.
